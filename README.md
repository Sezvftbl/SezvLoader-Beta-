# 🚀 SezvLoader (Beta)

**SezvLoader** is a high-performance, lightweight media downloader designed for speed and simplicity. Currently in active beta, it allows you to instantly save content from **TikTok, Instagram, and X (Twitter)**.

---

### 🐍 Requirements (Gereksinimler)
- **Python Version:** Python 3.10 or higher is recommended.
- **FFmpeg:** Ensure FFmpeg is installed on your system for high-quality video processing.

---

### 🛠️ Installation & Setup (Kurulum)

Follow these simple steps to get the app running:

1. **Install Dependencies:** Open your terminal (CMD) inside the project folder and run:
   ```bash
   pip install customtkinter yt-dlp gallery-dl requests pillow
Run the App: - Easy Way: Just double-click START.bat.

Manual Way: Run python sezv_downloader.py in your terminal.

✨ Features
Multi-Platform: Fast downloads from TikTok, Instagram, and X.

Modern UI: Clean, dark-themed interface powered by CustomTkinter.

Batch Download: Support for multiple links and history tracking.

Cookies Support: Includes pre-configured cookie management for seamless access.
